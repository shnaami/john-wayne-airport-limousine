# John Wayne Airport Limousine

SEO-focused Next.js website for johnwayneairportlimousine.com.

## Google Analytics 4
Set the Vercel environment variable:

NEXT_PUBLIC_GA_ID=G-XXXXXXXXXX

The GA4 loader is already built into `app/analytics.tsx`.

## Domain
Connect `johnwayneairportlimousine.com` and `www.johnwayneairportlimousine.com` in Vercel, then submit `/sitemap.xml` to Google Search Console.
